# Support

## Getting Help

- **Documentation:** See [QUICK_START.md](QUICK_START.md) for setup, [docs/runbooks/](docs/runbooks/) for operations
- **Issues:** Search [existing issues](https://github.com/scottschreckengaust/framework-for-github-app-on-aws/issues) first
- **New issue:** Use the [issue templates](https://github.com/scottschreckengaust/framework-for-github-app-on-aws/issues/new/choose)

## What to Expect

This is a maintainer-supported project. Response times are best-effort — there are no guaranteed SLAs.

Bug reports with reproduction steps and PRs with tests get priority.

## Security Issues

Do NOT open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md) for reporting instructions.

## Scope

This project provides a **framework** for building GitHub Apps on AWS. Support covers:

- CDK construct usage and configuration
- Webhook pipeline behavior
- OAuth and credential management
- Bot command routing

Out of scope: general AWS/CDK questions, GitHub API usage unrelated to this framework.
